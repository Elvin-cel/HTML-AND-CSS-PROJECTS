# Academy Cinemas

A responsive movie theater website built with Bootstrap 5.

## Files
- `index.html` — page structure, Bootstrap components, cards, showtime table, newsletter form, and footer.
- `styles.css` — custom styling and responsive enhancements.

## Run
Open `index.html` in your browser. Bootstrap is loaded from the CDN, so an internet connection is needed.
