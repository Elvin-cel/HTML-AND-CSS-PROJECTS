# Academy Cinemas
Bootstrap 5 responsive cinema page. Poster images are included as local SVG files, so they do not rely on external image hosts.

## Files
- `index.html`
- `styles.css`
- `images/movie1.svg`, `movie2.svg`, `movie3.svg`

Open `index.html` in your browser. Bootstrap styles and scripts load from CDN, so an internet connection is required for Bootstrap components.

## Assignment features
- Bootstrap responsive navigation
- Bootstrap cards and grid
- Local poster graphics
- Showtimes table
- Newsletter form
- Footer
- Responsive layout and hover effects
